# SceneArtRequest

Carries a bounded set of authored scene-layer keys. `SelectedActionType` is validated against the active reached choice or its persisted consequence before pending work is prioritized. The after-choice background is not authored until a supported reached outcome has been read from the active event; arbitrary keys, stale actions, and unsupported outcome context are rejected or reported unavailable. The request never carries Thread IDs, player appearance, profile data, or freeform action text.
