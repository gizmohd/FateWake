# SceneArtEndpoints

Maps the allowlisted scene-art request route and immutable image-delivery route. Selected action hints are verified against the active reached beat; the after-choice background receives only a fixed visual description of a persisted supported outcome read while holding the survivor lock. Unsupported personalized context is not sent to prompt authoring. Scene resolution detects incomplete approved assets and queues a durable replacement generation instead of reporting them ready. The binary endpoint resolves only approved database metadata and registered delivery derivatives (never archival masters), returns content-hash ETags, and checks account ownership before serving private assets. Public shared artwork is immutable-public; private character art uses private caching.
