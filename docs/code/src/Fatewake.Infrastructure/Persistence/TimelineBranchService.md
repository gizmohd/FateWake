# TimelineBranchService

Owner-only transactional fork and switch operations. Stable survivor identity selects a separate personal timeline with independent episode/facts/Wakes and frozen inherited panels. Parent ledger records are causal anchors, not replayed events. Request keys reject mismatched retries; stale active timelines conflict. Unsupported shared-world branching is rejected. Fresh Day 1 is a new canonical opening, not a reconstruction of an unrecorded past.
