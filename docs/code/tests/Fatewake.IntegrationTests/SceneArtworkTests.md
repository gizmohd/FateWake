# SceneArtworkTests

Exercises scene-art catalog assembly, API resolution/reuse, durable work status, private ownership and derivative-only delivery without an external image provider.

Style contract cases copy the bundled Markdown catalog into an isolated temporary directory. Distinct test style text proves that every authored layer reads the shared positive/negative sections and declared revision, supporting both LF and CRLF documents without exporting review prose. Canonical Michelle identity/clothing, subject-first construction and role exclusions must survive assembly.

Changing the positive style, exclusions or revision changes the visual fingerprint; identical inputs remain deterministic. Missing files, missing/empty/duplicate sections and an invalid versioned title fail explicitly. The shipped catalog must not reintroduce a blanket anime/manga exclusion. Fixtures are removed after each case; no production assets are mutated or generated.

A saved administrator correction is applied directly through `SceneArtRevision` to verify that shared style, negative instructions and version provenance survive the correction prefix while the corrected request has a distinct deterministic identity. This isolates style compatibility from review-route authentication.
